# Flight Hacker Pro ✈️

> Advanced Chrome Extension for Google Flights: True price baggage calculators, Point-of-Sale (POS) currency arbitrage, flexible 90-day matrix scanning, time/cost tradeoffs, comfort analytics, lounge & visa assistance, and self-transfer segregations.

## Features

- **True Price Baggage Calculator**: Calculate full trip costs with carry-on and checked luggage fees factored into flight comparisons.
- **POS Currency & Regional Arbitrage**: Detect and compare airfare pricing variations across international Google Flights regional domains and currencies.
- **90-Day Flexible Matrix Scanning**: Uncover cheapest departure windows across dates.
- **Comfort & Time Analytics**: Score flight quality, layovers, self-transfers, and flight durations against net monetary savings.
- **Lounge & Visa Assistant**: Direct travel requirement guidance and terminal amenities.

## Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/pradeepp511/Flight-Hacker-Pro.git
   ```
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle switch in the upper-right corner.
4. Click **Load unpacked** and select this project directory.
5. Navigate to [Google Flights](https://www.google.com/travel/flights) and start searching!

## Tech Stack
